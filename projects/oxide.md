# Oxide

Oxide is a self-hosted Twitch bot built in Rust. It connects to Twitch using OAuth authentication and the EventSub WebSocket interface.

The bot can listen to chat messages, send messages as its authenticated Twitch account, detect spam, delete spam messages and ban spam accounts.
